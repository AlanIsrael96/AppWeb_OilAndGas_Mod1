# Oil & Gas Engineering Dashboard

Aplicación Streamlit desarrollada para el **Bootcamp Data Analytics for Oil & Gas** de SPE Ecuador Section.

## Módulos

- **Producción:** IPR compuesta para un yacimiento subsaturado, con transición automática en el punto de burbuja.
- **Perforación:** gradiente y presión hidrostática del lodo usando TVD, con diagnóstico de balance.
- **Reservorios:** estimación volumétrica de POES y petróleo potencialmente recuperable.

## Ejecución local

```bash
pip install -r requirements.txt
streamlit run app.py
```

Para desplegar en Streamlit Community Cloud, selecciona este repositorio y usa `app.py` como archivo principal.

> Nota: el nombre del participante se encuentra en `app.py` y puede modificarse fácilmente antes de publicar.
